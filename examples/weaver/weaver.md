# Glossary

- **prime** — A C*-algebra $\mathcal A$ is prime if $I\cap J\ne0$ for any two nonzero closed two-sided ideals $I,J$. For closed ideals of a C*-algebra $IJ=I\cap J$, so this is the same as $IJ\ne0$.
- **primitive** — $\mathcal A$ is primitive if it has a [[faithful]] [[irreducible]] representation.
- **irreducible** — A representation $\pi\colon\mathcal A\to B(H)$ is irreducible if $\pi\ne0$ and the only closed subspaces invariant under $\pi(\mathcal A)$ are $0$ and $H$. Equivalently, every nonzero vector of $H$ is cyclic.
- **faithful** — A representation $\pi$ is faithful if $\ker\pi=0$.
- **separable** — $\mathcal A$ is separable if it has a countable norm-dense subset.
- **cylinder** — For $a\in\mathbb R^n$ the cylinder $X_a=\{x\in X:\ x_i=a_i,\ 1\le i\le n\}$ is the set of sequences that begin with $a$.
- **state** — A state of $\mathcal A$ is a positive linear functional $\rho$ on $\mathcal A$ with $\|\rho\|=1$.
- **generated | ideal generated** — The ideal generated by an element $P$ is the smallest closed two-sided ideal that contains $P$; in an algebra generated by a self-adjoint set $G$ that contains $P$ it is the closed linear span of the finite products of elements of $G$ in which $P$ occurs.
- **cyclic** — A representation $\pi$ on $H$ is cyclic if some vector $\xi$ is cyclic, that is, $\pi(\mathcal A)\xi$ is dense in $H$.
- **pi | partial isometry** — An operator $V$ is a partial isometry if $V^*V$ is a projection; then $VV^*$ is a projection too, and $V$ maps the range of $V^*V$ isometrically onto the range of $VV^*$ and kills the orthogonal complement.

### Why? after 1.7
**Why is $\pi(I)H$ dense, and why is $JI$ inside $I\cap J$?** Because the closure of $\pi(I)H$ is a nonzero subspace invariant under $\pi(\mathcal A)$, and an irreducible representation has no such subspace except $H$.

It is invariant since $\pi(a)\pi(i)h=\pi(ai)h$ and $ai\in I$ for $a\in\mathcal A$, $i\in I$. It is nonzero since $I\ne0$ and $\pi$ is faithful, so $\pi(I)\ne0$. Then $\pi(J)\ne0$ gives a $j\in J$ with $\pi(j)\ne0$ on the dense subspace $\pi(I)H$, so $\pi(ji)\ne0$ for some $i\in I$, and $JI\ne0$. Finally $ji\in J$ because $J$ is a right ideal and $ji\in I$ because $I$ is a left ideal, so $JI\subseteq I\cap J$.

**Where will non-separability enter?** In the count of orthogonal projections. On each level of a tree the algebra will contain $2^{\aleph_0}$ mutually orthogonal projections, and a state is nonzero on only countably many of them, since its values on any finitely many orthogonal projections add up to at most 1. A separable algebra has no room for this. Two orthogonal nonzero projections $p,q$ satisfy $\|p-q\|=1$, so a separable algebra contains at most countably many mutually orthogonal nonzero projections. (Dixmier's proof itself is not needed here.)

### Why? after 5.5
**Why is a product of operators $V_{a,b}$ again some $V_{a,b}$, or zero?** Because two prefix replacements in a row are again one prefix replacement, as long as the prefixes fit together; if they do not, the product is zero.

In detail, $V_{a,b}V_{c,d}$ first replaces the prefix $c$ by $d$, then the prefix $a$ by $b$. It is nonzero only if $X_d\cap X_a\ne\varnothing$, that is, one of $a,d$ extends the other.

If $a=d\,u$, the product sends $c\,u\,v$ to $b\,v$, so it equals $V_{cu,\,b}$. If $d=a\,u$, it sends $c\,w$ to $b\,u\,w$, so it equals $V_{c,\,bu}$. In both cases the two tuples have equal length.

### Why? after 6.6
**Why do links give primeness, and vanishing states non-primitivity?** Because a link carries a projection of one ideal into the other, and a faithful irreducible representation would give a state that vanishes on no nonzero ideal.

*Prime.* Let $I,J$ be nonzero ideals, $P\in I$ and $Q\in J$ cylinder projections, and let some $V_\sigma$ link $P'\le P$ to $Q'\le Q$. Then $P'=P'P\in I$, so $Q'=V_\sigma P'V_\sigma^*\in I$, and $Q'=Q'Q\in J$. Hence $0\ne Q'\in I\cap J$.

*Not primitive.* Let $\pi$ be a faithful irreducible representation on $H$ and $\xi\in H$ a unit vector; then $\rho(x)=\langle\pi(x)\xi,\xi\rangle$ is a state. If $\rho$ vanishes on a nonzero ideal $I$, then $\|\pi(x)\xi\|^2=\rho(x^*x)=0$ for $x\in I$, hence $\langle\pi(x)\eta,\xi\rangle=\langle\eta,\pi(x^*)\xi\rangle=0$ and $\xi\perp\pi(I)H$. On [[slide:Prime and primitive]] we saw that $\pi(I)H$ is dense, so $\xi=0$, a contradiction. This is the argument of Weaver's theorem [W, §2].

### Why? after 14.5
**Why does $b$ extend $a_\kappa$, and why is $P_{b'}A=A$?** Because otherwise $V_\kappa$ would kill the range of $B$, and $A$ would be zero.

The tuple $a_\kappa$ has length $n_\kappa<n\le|b|$, so either $b$ extends $a_\kappa$ or $X_b\cap X_{a_\kappa}=\varnothing$. Properties (2) and (3) speak only of the value at coordinate $n$, which has not changed.
